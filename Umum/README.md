# Informasi Umum Praktikum

Folder ini berisi informasi-informasi mengenai pelaksanaan praktikum.

---

## Daftar Dokumen

* **`Format Laporan Praktikum.docx`**: Template resmi penyusunan laporan praktikum. Semua praktikan wajib mengikuti format ini.
* **`Petunjuk Penggunaan Notepad++.pdf`**: Panduan penggunaan Notepad++ sebagai syntax highlighter untuk keperluan praktikum.
