# Tugas Praktikum

Folder ini berisi instruksi dan soal tugas yang wajib dikerjakan pada repositori pribadi masing-masing praktikan.

---

## Pengumpulan Tugas
1. Baca Tugas
2. Kerjakan sesuai instruksi
3. Kumpulkan tugas pada **repositori pribadi** (`Nama-NRP`).
4. Pastikan struktur folder pada **repositori pribadi** sesuai ketentuan.
5. Kumpulkan tugas sebelum waktu *deadline* yang ditentukan.
6. Instruksi pengumpulan tugas ada pada file **README.md** di **repositori pribadi** masing-masing praktikan.
7. Instruksi pengerjaan tugas ada pada file .pdf di folder **Tugas**.
